# 06 — MVP 范围

> 本文件是"做 / 不做"的范围权威。安全约束见 docs/10（优先级更高）。

## 一句话范围

六个页面，两条最高频路径：**闪回急救**（危机）与**内在批判者挑战**（日常），辅以哀悼、心理教育、方法库。核心确定性、可离线，AI 只做辅助。

## 在范围内（MVP 必做）

### 六个页面

| 页面 | 一句话职责 | 对应方法 |
|------|-----------|---------|
| Home | 此刻枢纽：大按钮"我正闪回"+"内在批判者在攻击我" | 入口 |
| Rescue（闪回急救） | 13 个闪回步骤 + 接地 + 转介 | A01–A05、G03 |
| Critic（内在批判者挑战） | 14 种攻击 → 思维纠正 → 用自己的话重写 | B01–B04 |
| Grieve（哀悼与情绪） | 愤怒/哭泣/口头宣泄/感受 | C01–C07 |
| Learn（了解自己） | 4F、毒性羞耻、感恩、闪回 vs 事实 | F01–F04、G01–G02 |
| Methods（方法库） | 29 个方法只读参考 | 全部（含 D/E 二期方法） |

### 确定性工具（无 AI 也能跑，最高优先级）

1. 闪回急救引导（A01：13 步逐条，可跳过）
2. 接地练习（A04：呼吸引导 + 身体扫描，可离线）
3. 内在批判者 14 攻击 → 思维纠正卡片（B01）
4. 思维阻断按钮 + 自定义阻断语句（B02）
5. "我的优点与成就"清单（B03）
6. 危机检测 + 转介（程序确定性，见 docs/10）
7. 4F 自评卡（非诊断）+ 毒性羞耻提示卡（F01/F02/F04）
8. 感恩清单（F03，注明"不在闪回时做"）

### AI 层（最后接，辅助型，见 docs/09）

- 识别用户正遭受哪种内在批判者攻击（B01 的 14 选一）
- 把用户的自我批判想法改写得更温和（B03 辅助）

## 明确不在范围内（现在不做）

| 领域 | 原因 |
|------|------|
| 诊断 / 治疗 / 医疗建议 | 安全红线（docs/10） |
| 自由对话聊天机器人 | 与定位相悖；AI 只做结构化辅助 |
| 深挖创伤记忆回放 | 安全红线（docs/10） |
| 成瘾 / 解离 / 严重抑郁干预 | 转介，不做自助 |
| 账号 / 云同步 / 社交 / 复杂 SaaS | MVP 本地单用户 |
| 二期工具（自我母育/父育、关系权利、有爱化解冲突） | 方法在库可读，交互工具二期做 |

## 非功能性约束

- **核心疗愈流程可离线**：闪回急救、接地、思维纠正不依赖 AI 或网络。
- **本地单用户**：localStorage / IndexedDB，不引后端。
- **低刺激视觉**：低饱和、柔和、大字号；不做强动效。
- **安全护栏从第一屏内置**：危机检测、接地、可停、转介（docs/10）。
