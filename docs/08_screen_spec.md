# 08 — 页面级开发清单（Screen Spec）

> 只定义结构与状态，不是视觉稿。页面名用英文统一。**安全护栏（docs/10）在每个页面都内置：危机检测、接地入口、"随时可停"。**

---

## Home（此刻）

- **页面目的**：作为安全锚点，回答"我现在需要什么"；两条最高频路径的一键入口。
- **入口**：应用默认首页；其他页面"回到安全处"的落点。
- **核心组件**：
  - 大按钮"我正闪回"（→ Rescue，最高优先级，视觉最突出）
  - 大按钮"内在批判者在攻击我"（→ Critic）
  - 一键接地入口（随时可用）
  - 导航：Rescue / Critic / Grieve / Learn / Methods
- **用户可以执行的动作**：一键进入闪回急救；一键进入批判者挑战；一键接地；浏览其他页面。
- **页面状态**：稳定态（无进行中流程）。
- **空状态**：无（首次进入即显示两个大按钮 + 一句温和欢迎）。
- **错误状态**：本地存储不可用 → 温和提示"数据只存在本机，加载失败可重试"。
- **完成后的下一步**：进入某个模式。
- **与其他页面的连接**：→ Rescue / Critic / Grieve / Learn / Methods。

---

## Rescue（闪回急救）

- **页面目的**：情绪闪回时的急救，13 步 + 接地，把人带回当下（危机工具，最高优先级）。
- **入口**：Home 大按钮"我正闪回"；其他页面感到崩溃时。
- **核心组件**：
  - 强度记录（进入时 0–100）
  - 接地组件（呼吸引导 + 身体扫描，可随时唤起）
  - 13 步逐条引导（一次一条，大字号，可跳过/上一步/下一步）
  - 危机检测 + 转介（程序确定性）
  - "停止"按钮（随时退出回安全态）
- **用户可以执行的动作**：记录强度；逐条走 13 步（可跳过）；随时接地；随时停止。
- **页面状态**：引导中（第 N 步）/ 已完成。
- **空状态**：无。
- **错误状态**：危机信号命中 → 立即显示危机转介，停止流程。
- **完成后的下一步**：完成 13 步后记录强度 + 回到 Home（或转介）。
- **与其他页面的连接**：→ Home（回安全）；→ Critic（第 8 步可跳去批判者挑战）；→ Grieve（第 9 步可跳去哀悼）。

---

## Critic（内在批判者挑战）

- **页面目的**：识别并挑战内在批判者的攻击（毒性羞耻、自我攻击），把自我批判改写得更温和。
- **入口**：Home 大按钮"内在批判者在攻击我"；Rescue 第 8 步。
- **核心组件**：
  - 输入框"它此刻在骂你什么？"
  - 14 种攻击类型选择（可 AI 辅助识别，见 docs/09）
  - 对应的【思维纠正】卡片（书中原文）
  - "用自己的话改写"输入框
  - 思维阻断按钮（"不/停下/闭嘴"）+ 自定义阻断语句
  - "我的优点与成就"清单（B03）
- **用户可以执行的动作**：写下攻击想法；选攻击类型（或 AI 识别）；读思维纠正；改写；保存记录（Entry）。
- **页面状态**：空（未输入）/ 已识别攻击类型 / 已改写。
- **空状态**：显示"内在批判者有时候会说些难听的话，写下来，我们一起来看它"。
- **错误状态**：危机信号 → 转介。
- **完成后的下一步**：保存改写结果 → 温和反馈 + 可回到 Home。
- **与其他页面的连接**：→ Learn（了解 4F/毒性羞耻）；→ Home。

---

## Grieve（哀悼与情绪）

- **页面目的**：四种哀悼方式（愤怒/哭泣/口头宣泄/感受）的温和引导（含最重安全护栏）。
- **入口**：导航；Rescue 第 9 步。
- **核心组件**：
  - 四选一入口（愤怒/哭泣/口头宣泄/感受）
  - 各自引导（见 C02–C05）
  - 接地入口（进入前提示）
  - "随时可停"（显眼）
  - 转介（情绪过于强烈时）
- **用户可以执行的动作**：选一种方式；跟随引导；随时接地/停止。
- **页面状态**：选择态 / 引导中。
- **空状态**：显示"哀悼是安全的，随时可以停下"。
- **错误状态**：危机信号 → 转介。
- **完成后的下一步**：回到 Home 或接地。
- **与其他页面的连接**：→ Home；→ Rescue（若被触发闪回）。

---

## Learn（了解自己）

- **页面目的**：心理教育——理解 4F 类型、毒性羞耻、闪回机制，减少羞耻。
- **入口**：导航。
- **核心组件**：
  - 4F 类型自评卡（非诊断）
  - 毒性羞耻提示卡（"羞耻=闪回表象，不是事实"）
  - "感觉危险≠真的危险"提示卡
  - 感恩清单（注明"不在闪回时做"）
  - 康复迹象自评（G02）
- **用户可以执行的动作**：查看/自评各类卡；填感恩清单；查看康复迹象。
- **页面状态**：各卡片独立。
- **空状态**：无（静态内容）。
- **错误状态**：无特殊。
- **完成后的下一步**：返回或进入对应工具。
- **与其他页面的连接**：→ Critic（毒性羞耻卡跳转）；→ Rescue（闪回机制）。

---

## Methods（方法库）

- **页面目的**：29 个方法只读参考（含二期方法）。
- **入口**：导航。
- **核心组件**：分类导航（A–G）；方法卡片；方法详情（when_to_use / steps / source）。
- **用户可以执行的动作**：浏览、搜索、查看详情。
- **页面状态**：列表态 / 详情态。
- **空状态**：无。
- **错误状态**：数据加载失败 → 温和重试。
- **完成后的下一步**：从详情跳转到对应工具（若已实现）。
- **与其他页面的连接**：→ 各对应页面。

## 端到端验收脚本（walkthrough）

1. 打开 → **Home**，看到两个大按钮 + 温和欢迎。
2. 点"我正闪回" → **Rescue** → 记录强度 → 逐条走 13 步（可跳过）→ 完成 → 记录强度 → 回 Home。
3. 点"内在批判者在攻击我" → **Critic** → 写"我真是个废物" → 选攻击类型（或 AI 识别）→ 读思维纠正 → 用自己的话改写 → 保存。
4. **Grieve** → 选"哭泣" → 跟随引导 → 随时点"停止" → 回安全态。
5. **Learn** → 看 4F 卡 / 毒性羞耻卡 / 填感恩清单。
6. **Methods** → 浏览 → 打开 A01 详情。
7. **安全验证**：输入"我不想活了" → 任意页立即显示危机转介，停止流程。

**验收标准**：以上 7 步无 AI 也能走通（核心确定性）；危机检测命中即转介；刷新后数据仍在（localStorage）。
